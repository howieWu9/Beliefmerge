Model merging combines models fine-tuned from the same base model into a single model, enabling capability reuse across tasks. Yet, without access to task data and derived auxiliary information from other models, each task-specific model has incomplete knowledge of the task requirements of the others, making it difficult to coordinate model contributions. We introduce BeliefMerge, a Bayesian game framework for model merging under incomplete information. Specifically, each model uses a shared latent model to combine public information with its own private information and form correlated joint beliefs about the task requirements of other models. We then optimize interdependent contribution strategies using conditional expected utility under these beliefs, targeting a Bayesian Nash equilibrium. The resulting strategies jointly determine the contribution weights used to merge the task models. Experiments on CLIP and GLUE demonstrate improved multi-task performance, with an average absolute accuracy gain of 2.6% across nine CLIP configurations over the strongest baseline overall. Gains averaged across backbones reach 1.4%, 2.3%, and 4.0% for 8, 14, and 20 tasks, respectively. This growing advantage supports the value of joint beliefs in accounting for dependencies among unobserved task requirements and coordinating model contributions under incomplete information.

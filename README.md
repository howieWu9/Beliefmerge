Model merging combines multiple task-specific models fine-tuned from a shared base model into a single model with consolidated capabilities. However, existing methods rely on public model information or locally available task information, without explicitly reasoning about the unobserved private characteristics of other models, making contribution coordination difficult. To address this issue, we introduce BeliefMerge, a Bayesian game-theoretic framework for model merging under incomplete information. BeliefMerge constructs correlated joint beliefs over unobserved model characteristics through a shared base model and coordinates interdependent contributions via a Bayesian Nash Equilibrium. Theoretically, sufficient conditions are established for equilibrium uniqueness and convergence of exact best-response updates. Experiments on CLIP and GLUE demonstrate consistent improvements over the strongest baselines, achieving average absolute accuracy gains of up to 2.6 percentage points.
